Imani referee

Paste the viewing key of any sealed-bid auction on Zcash, and the blocks it ran in. In seconds this page reads those blocks, counts the bids, finds the winners and the price, and checks that every refund was paid exactly as the rules say. It works on rounds Imani did not run.

What leaves your browser: only requests for blocks, one per block, saying the network (main or test) and the block number. Your key is never sent anywhere. It is read in this tab and not stored.

Back to the offline checker, which uploads nothing at all and works from the seller's files.

1. Say which round

One press fills the boxes below with a real auction Imani ran on the public Zcash test network on 11 Oct 2026 (3 bids, 2 items) and checks it. Test coins have no value.

A read-only key that starts with uview1 (main network) or uviewtest1 (test network). A seed phrase or a spending key is refused before anything is requested.

1 ZEC is 100,000,000 zatoshis. The first block is when bidding opened. The last block is when every refund was due. The lot name is read from the bid memos, so fill it in only if the key shows more than one lot. If you leave the close block empty, every bid in the range counts as on time.

How it works

  • The blocks come from two block servers run by different operators: a Zcash light wallet server and a public explorer. A block is used only when both give the same block and the same transactions, and each transaction's bytes hash to its id. Both answers are shown with the result.
  • Those servers do not accept requests from a web page, so a small relay program (tools/referee-serve.ts) makes the requests for this page. It takes a network and a block number, nothing else, and it has no way to receive a key.
  • The key is used here, in your browser, with the same decoder and the same checker as the command line tool. The bids, winners, price and refunds are recomputed from the blocks alone, then compared with the refunds the lot really paid.
  • This page makes network requests, which the offline checker never does. Use the offline checker when you want nothing to leave your device.
